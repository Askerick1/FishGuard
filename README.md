Русский
FishGuard — расширение для браузера, которое помогает распознавать фишинговые ссылки и предупреждает о подозрительных сайтах.

Установка:
1. Скачайте проект с GitHub через Code → Download ZIP и распакуйте архив.
2. Откройте в Chrome страницу расширений и включите Режим разработчика.
3. Нажмите Загрузить распакованное расширение и выберите папку extension.

English
FishGuard is a browser extension that helps detect phishing links and warns users about suspicious websites.

Installation:
1. Download the project from GitHub using Code → Download ZIP and extract the archive.
2. Open the extensions page in Chrome and enable Developer mode.
3. Click Load unpacked and select the extension folder.
